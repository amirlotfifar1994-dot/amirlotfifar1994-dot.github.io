Case evidence standard

A complete case study should go beyond before/after photos

For a case to support a technical decision, these six data groups should be recorded where possible. Current examples make claims only where evidence is available.

01

Part & substrate

Material, dimensions, initial surface condition and previous coating.

02

Project objective

Color, gloss, use case and expected acceptance criterion.

03

Process route

Preparation, masking and process route to the extent publishable.

04

Quality control

Visual inspection and any tests agreed for that project.

05

Production scope

Prototype, trial batch or production quantity without turning one result into a general claim.

06

Result boundaries

What was measured, what was only observed, and what data was not published.

This framework is intended for new cases so the portfolio can evolve from an image gallery into an evidence-based project archive.

A professional comparison method

Treat the photo as an initial reference, not a color-match guarantee

Ambient light, display calibration, substrate and polish quality all affect visual perception. For sensitive projects, a physical reference or pre-production sample is a safer decision route.

  1. 01
    Define the substrate and current surface

    Raw, polished, plated or previously coated surfaces behave differently.

  2. 02
    Separate color from finish

    Gold is one decision; mirror, gloss, satin or matte is another.

  3. 03
    Add real operating conditions

    Touch, moisture, cleaners, abrasion and temperature can change the suitable route.

For a real project review

Send part photos, material, quantity and target finish

If you have a color reference or physical sample, mention it from the start to make the review shorter and more precise.
